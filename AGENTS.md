## Impeccable

- Untuk pekerjaan UI/UX, wajib gunakan skill `$impeccable` dan jalankan `context` satu kali pada setiap session sebelum mengubah antarmuka. Ikuti directive dari context dan gunakan command Impeccable yang sesuai scope.

## Aturan kerja project

1. Pada awal setiap session, wajib membaca `AGENTS.md` sepenuhnya dan mengikuti seluruh aturan di dalamnya.
2. Selalu gunakan Graphify terlebih dahulu untuk memahami project atau source. Source code mentah hanya boleh dibaca bila data/source Graphify tidak ditemukan atau belum mencakup kebutuhan konteksnya.
3. Setiap perubahan pada project wajib diikuti pembaruan Graphify sebelum pekerjaan dinyatakan selesai.
4. Jangan melakukan overengineering.
5. Jangan membuat solusi terlalu rumit; pilih implementasi yang sederhana dan sesuai kebutuhan.
6. Jangan melakukan improvement, inisialisasi, refactor, atau perubahan apa pun di luar scope yang disetujui.
7. Lakukan testing yang proporsional pada setiap perubahan.
8. Jika perintah, instruksi, atau prompt dari user kurang jelas, ambigu, atau scope-nya belum cukup untuk ditentukan dengan aman, wajib menanyakan klarifikasi dan menunggu jawaban user sebelum melanjutkan. Jangan membuat asumsi untuk bagian yang belum jelas.
